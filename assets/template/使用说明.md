# 审美库

日常只需要打开 `设计工作室画廊.base` 和 `设计内容画廊.base`。

## 流程

1. `setup` 生成工作室卡并建立历史基线。
2. `sync` 每周对比官方来源与历史账本。
3. 新项目先进入 `_系统/订阅源/本周新增候选.json`。
4. 经过 AI 编辑和人工确认后，再生成内容卡或加入本周精选。

## 命令

```bash
python3 _系统/manage.py setup --workers 10
python3 _系统/manage.py check
python3 _系统/manage.py sync --workers 10
```

`_系统/订阅源/工作室来源.json` 是唯一的工作室配置。请使用官方来源，无法稳定识别独立项目时，将规则设为 `watch_only`。
